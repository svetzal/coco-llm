Real numbers, exported from the reference model. Say that out loud once. Step through: the context is two tokens. They become three numbers. Those three numbers give a score to all 29 tokens. The right answer is AMIGA and it gave AMIGA 3.5%, which is barely better than guessing at 1 in 29. So nudge the weights that produced that score. Three numbers move. AMIGA goes to 4.9%. THAT IS THE WHOLE ALGORITHM. Everything after this is doing it 58 times an epoch, 60 epochs, on a machine from 1981.

By epoch 20 it has collapsed onto one answer and more training does not help. The loss keeps falling and the output stops improving. Same lesson as the epoch sweep in EXP-007: more training is not more useful, and we only know that because we measured the behaviour we cared about instead of the number the optimizer gave us.

Watch it learn

EXP-004 · the live training run

THE CENTREPIECE. Reset to random weights, seed 6809, generate nonsense. Start training. While epochs run, walk one step: scores, softmax, error, backpropagation, update. Pause at PRESS ANY KEY, let the room choose when to infer. Repeat seed 6809 and compare. Two unsigned MULs only if the run gives you time. Best code beat, first to drop. LENGTH UNMEASURED. Eleven minutes is a planning figure. If it does not improve, say so and inspect the evidence together. A recorded run is a labelled comparison, never a substitute.

EXP-011 · the context-editing attention head

Most direct bearing on what people already use. Protect its time. Retrieve LISA = CODE 2. Open the editor, type 6, show BEFORE, AFTER, and MODEL 751B DID NOT CHANGE. Things that never existed

EXP-012 · the fake episode titles

One keystroke, sixteen invented titles. The lesson is the split and it is visible in the sizes: 400 bytes of model holding the shape of a title, 1,600 bytes of dictionary and rules holding the words. It never learned what a Gothos is. It learned that something goes there. Corpus number reframes it: across all 79 real titles, only two adjacent word pairs ever repeat. Nothing to generalize from. It memorized a shape. FIRST TO CUT. Also the one place we leave the vintage-computer example, so get in and out.

the upbringing

EXP-003 · the fan-corpus bias runs

Same architecture, same initial weights, same budget, same vocabulary, same sampling seed. Different data. Different machine. Then the harder half: the same balanced examples concatenated and interleaved produce different behaviour. Order is a choice too, and nobody set out to make it one. Ask which human decision produced each behaviour. DO NOT ANSWER IT.

Now you play it

EXP-013 · the game opponent that learns

NEVER CUT. Someone from the room calls throws. It does not know the rules: RULES 0/25 says so. It does not know the player either: MEMORY n/rounds says how little it has. Both stay on screen. Six or eight rounds. It states its expectation BEFORE each throw. Around twenty-five rounds it has the rules; it never finishes learning the person. Press R in front of them and let it fall over. QUOTE THE HUMAN NUMBER: 80% against six synthetic players with habits. 52.8% against a recorded 200-round session with a person who was trying. Better than chance at three sigma, nowhere near enough to win. Five of six synthetic players had a habit and one did not. A person plays like the one that did not. The test set encoded an assumption about people and the average hid it. 100 bytes. No neural network. A tiny table beat every model we tried, which is why there is no model in there at all. Invite whoever played to the table.
