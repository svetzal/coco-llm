# Audience-card visual concepts

These four portrait studies explore a printed “be the model” activity. They
share the same interaction: read the current context, roll a twenty-sided die,
use the probability table to choose the next token, and carry the new context
to another card.

| File | Direction |
| --- | --- |
| `concept-a-manual-cover.png` | Dense vintage manual-cover treatment |
| `concept-b-screen-manual.png` | CRT display with numbered instructions |
| `concept-b2-coco-screen.png` | Cleaner CoCo green-screen variation |
| `concept-c-token-track.png` | Card-game layout with an explicit context flow |

These are exploratory generated images, not approved print files. The
probability values and visible token examples are conceptual and must be
checked against the final exercise data before production. Approved wording
lives in [`../exhibit-copy.md`](../exhibit-copy.md), and the activity design
lives in [`../table-exercises.md`](../table-exercises.md).
