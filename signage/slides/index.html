This computer is teaching itself to talk

It arrived under a Christmas tree 45 years ago. Right now it is starting from random numbers and inventing computer names that never existed.

How?

  1. Guess the next word.
  2. Measure how wrong you were.
  3. Nudge.
  4. Repeat.

Same trick as ChatGPT.

Does it understand?

It has never seen a computer. It does not know Commodore is a company. It knows that AMIGA often follows COMMODORE. That is all it knows.

Prediction is not understanding.

Roll the dice and be the model

  1. Take a card from the table.
  2. Roll the d20. Read off the word.
  3. Write it down. Take the next card.
  4. Stop when the roll says stop.
