A 45-year-old computer, can it do modern machine learning?

The Color Computer 1 on this table trains a small language model. It starts from random numbers and learns to write computer names.

How?

  1. Guess the next word.
  2. Measure how wrong you were.
  3. Nudge.
  4. Repeat.

ChatGPT learns with the same loop, at a far larger scale.
